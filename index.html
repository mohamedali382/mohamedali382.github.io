LLMtron

An automated security-testing framework that attacks LLM agents and MCP systems the way a real adversary would, then scores what got through against the OWASP LLM Top 10.

  • Delivers adversarial prompts through five vectors: direct, MCP, RAG, memory and PDF.
  • Generates payloads from a curated library and a LoRA fine-tuned model, and a PAIR refinement loop improves attacks that failed.
  • Judges responses with a five-layer pipeline: audit-log and database diffing, plus semantic classification with MiniLM and DeBERTa.
  • Rates severity with a hybrid CVSS, MAESTRO and ATFAA model.
  • Benchmarked against Garak, PyRIT and NeMo Guardrails, with stronger coverage of RAG, MCP and multi-turn attacks.
